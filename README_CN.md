## 为什么选择 PromptVault？

大多数提示词库只是平铺列表。**PromptVault 完全不同。**

| 特性 | 常见仓库 | PromptVault |
|------|---------|-------------|
| 结构 | 扁平 CSV / MD 列表 | **带元数据的 JSON** — 分类、标签、难度、模型兼容性 |
| 语言 | 仅英文 | **双语** — 每条提示词中英对照 |
| 模型感知 | 无 | **兼容性标签** — 知道每条提示词最适合哪个模型 |
| 技巧教学 | 无 | **完整提示词工程指南** — CoT、Few-shot、思维树等 |
| 搜索 | Ctrl+F | **内置网页搜索工具** — 按分类、模型、难度筛选 |
| 质量 | 社区提交参差不齐 | **精选+验证** — 每条提示词经过实战测试 |
